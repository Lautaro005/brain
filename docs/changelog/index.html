v0.02.5
2026-09-28LatestÚltima

Memory that ages well

Search that finds exact names, facts with dates, summaries, entities in the graph, and a review that suggests fixes without touching anything.

New

  • Hybrid search. search_knowledge combines semantic search with an exact-keyword index (SQLite FTS5, BM25) merged by reciprocal rank fusion. Proper names, IDs, dates and numbers now show up. If Chroma or Ollama is down, keyword search keeps working.
  • Facts over time. Each memory is saved with its date. add_memory(fact, category, supersede=old) moves the old fact to a ## Historial section instead of leaving both. New tool memory_history(category).
  • Summaries. Pages over 800 words (and long connection results) get a short abstract from your local chat model; list_sources() returns it.
  • Entities in the graph. Sources, captures and memory files get an entities list. Notes that name the same person or project connect through a new Entity node type.
  • distill_skill(topic). Gathers everything brain has on a topic so your agent writes a skill from it.
  • Reflect (Profile tab). Finds duplicates, likely contradictions and notes without entities, and shows the tool call that would fix each one. It never writes.
  • reindex_keyword_search() and a Rebuild keyword index button, for sources saved before this version.
  • Documentation site (Docs) and this changelog.
  • SECURITY.md with how to report vulnerabilities privately.

Changed

  • The dashboard sidebar header shows just the logo and the name, aligned on one row.
  • The license is split in two files, LICENSE (MIT) and COMMONS-CLAUSE.md, so GitHub detects it. The terms don't change.

Upgrade notes

  • Run Rebuild keyword index once (Knowledge tab) so older sources are found by keyword.
  • Summaries and entities need a chat model: ollama pull llama3.2. Without it they're skipped.

Una memoria que envejece bien

Búsqueda que encuentra nombres exactos, hechos con fecha, resúmenes, entidades en el grafo y una revisión que sugiere arreglos sin tocar nada.

Nuevo

  • Búsqueda híbrida. search_knowledge combina la búsqueda semántica con un índice por palabra exacta (SQLite FTS5, BM25), fusionados con reciprocal rank fusion. Ahora aparecen nombres propios, IDs, fechas y números. Si Chroma u Ollama están caídos, la búsqueda por palabra sigue funcionando.
  • Hechos en el tiempo. Cada memoria se guarda con su fecha. add_memory(hecho, categoría, supersede=viejo) pasa el hecho viejo a una sección ## Historial en vez de dejar los dos. Tool nueva memory_history(category).
  • Resúmenes. Las páginas de más de 800 palabras (y los resultados largos de conexiones) llevan un abstract corto hecho por tu modelo de chat local; list_sources() lo devuelve.
  • Entidades en el grafo. Fuentes, capturas y archivos de memoria llevan una lista entities. Las notas que nombran a la misma persona o proyecto se conectan por un nuevo tipo de nodo, Entidad.
  • distill_skill(topic). Junta todo lo que brain tiene sobre un tema para que tu agente redacte un skill.
  • Reflect (pestaña Perfil). Encuentra duplicados, contradicciones probables y notas sin entidades, y muestra la tool que arreglaría cada una. Nunca escribe.
  • reindex_keyword_search() y un botón Reindexar búsqueda por palabra, para las fuentes guardadas antes de esta versión.
  • Sitio de documentación (Docs) y este changelog.
  • SECURITY.md con cómo reportar vulnerabilidades en privado.

Cambios

  • El encabezado del sidebar del dashboard muestra solo el logo y el nombre, alineados en una fila.
  • La licencia se separó en dos archivos, LICENSE (MIT) y COMMONS-CLAUSE.md, para que GitHub la detecte. Los términos no cambian.

Al actualizar

  • Corré una vez Reindexar búsqueda por palabra (pestaña Conocimiento) para que las fuentes viejas se encuentren por palabra.
  • Los resúmenes y las entidades necesitan un modelo de chat: ollama pull llama3.2. Sin él se saltean.
v0.02.1
2026-09-27

Fixes, and tools for any chat model

Fixed

  • The Profile tab failed to load ("list index out of range") when an agent rewrote profile.md without the expected blank line.
  • Notes with invalid YAML frontmatter (an unquoted : in a description) lost their description in the graph without warning. Every write now validates the frontmatter, repairs it when it can, or rejects the write with a clear error; reads never break.

New

  • set_frontmatter(path, fields): change metadata without rewriting the note.
  • Chat tools work with any model: schemas are cleaned up, and models that reject native tools (GGUF from Hugging Face) switch to a text mode with <tool_call> blocks.
  • Every tool call in the chat is listed and expandable, with its arguments and result, also when reopening a chat.

Changed

  • Redesigned chat: full-height, floating composer, user bubbles on the right.
  • The collapse button moved next to the logo and name.

Arreglos, y tools para cualquier modelo de chat

Arreglado

  • La pestaña Perfil no cargaba ("list index out of range") cuando un agente reescribía profile.md sin la línea en blanco esperada.
  • Las notas con frontmatter YAML inválido (un : sin comillas en una description) perdían la description en el grafo sin avisar. Ahora cada escritura valida el frontmatter, lo repara si puede o rechaza la escritura con un error claro; las lecturas nunca se rompen.

Nuevo

  • set_frontmatter(path, fields): cambiar metadatos sin reescribir la nota.
  • Las tools del chat andan con cualquier modelo: los esquemas se limpian, y los modelos que rechazan tools nativas (GGUF de Hugging Face) pasan a un modo texto con bloques <tool_call>.
  • Cada tool call del chat aparece listada y se despliega, con sus argumentos y resultado, también al reabrir un chat.

Cambios

  • Chat rediseñado: ocupa todo el alto, compositor flotante, burbujas del usuario a la derecha.
  • El botón de plegar pasó al lado del logo y el nombre.

v0.01.0
2026-09-27FirstPrimera

First release

  • MCP server with a Markdown vault: read, write, append, replace and delete notes; profile and memory; skills.
  • Save the web: save_url with trafilatura and a Playwright fallback for JavaScript sites; semantic search with Ollama (nomic-embed-text) and a shared Chroma server.
  • Version history in SQLite: file_history and restore_file, safe with several agents writing at once.
  • Dashboard (brain): service switches, metrics, system health, profile and memory import, graph, knowledge and logs, in English and Spanish.
  • Connect agent in one click: Claude Desktop, ChatGPT, Claude Code, Codex, Cursor, VS Code, Windsurf and Gemini CLI.
  • Connections: brain as an MCP client of other servers (local command, URL or Composio, with consumer and project keys), with results captured to memory.
  • One-command installer and website.

Primera versión

  • Server MCP con un vault en Markdown: leer, escribir, agregar, reemplazar y borrar notas; perfil y memoria; skills.
  • Guardar la web: save_url con trafilatura y fallback a Playwright para sitios con JavaScript; búsqueda semántica con Ollama (nomic-embed-text) y un server de Chroma compartido.
  • Historial de versiones en SQLite: file_history y restore_file, seguro con varios agentes escribiendo a la vez.
  • Dashboard (brain): switches de servicios, métricas, salud del sistema, perfil e importación de memoria, grafo, conocimiento y logs, en español e inglés.
  • Conectar agente en un click: Claude Desktop, ChatGPT, Claude Code, Codex, Cursor, VS Code, Windsurf y Gemini CLI.
  • Conexiones: brain como cliente MCP de otros servers (comando local, URL o Composio, con keys de consumidor y de proyecto), con los resultados capturados en la memoria.
  • Instalador de un comando y sitio web.
