v0.03.1
2026-10-04LatestÚltima

Fact check, graph changes you approve, and dated notes

A clearer chat, a way to verify claims with visible evidence, and a note format any AI can read.

New

  • Fact check (new view): verify claims with a visible process. brain searches your memory first and goes to the web only if that's not enough (and says so), reads every page in full, groups sources that aren't independent, looks for counter-evidence and gives a verdict by rules — supported, likely supported, mixed, inconclusive, likely false, false or not verifiable — with quotes, dates and limitations. Preferences (level, freshness, primary sources, regions, languages, search engine…) are set once. Also /factcheck in the chat and the fact_check tool. Nothing is saved to the vault unless you click Save to brain.
  • Graph changes with approval: to link or unlink notes, the chat (or an agent) proposes the change and you see an image of the graph with it marked in green or red. Approve, reject or undo; nothing changes before you approve.
  • Note format: every note now carries type, created and updated (compatible with the Open Knowledge Format), filled in automatically. Settings → Note format adds them to older notes.
  • The chat can answer with HTML (tables, collapsible sections, highlights, simple diagrams), safely sanitized.

Changed

  • The chat follows clearer working rules: understand the request, use just the tools it needs, answer with the result first. It no longer repeats the same tool call, and it always ends with an answer instead of stopping when it runs out of rounds.
  • Saved pages are split by sections and paragraphs (headings and code blocks stay whole), and keep their author and date when the page shows them.
  • The Manus Studio card no longer repeats the command and arguments shown further down.

Fact check, cambios en el grafo que aprobás, y notas con fecha

Un chat más claro, una forma de verificar afirmaciones con la evidencia a la vista y un formato de notas que cualquier IA entiende.

Nuevo

  • Fact check (vista nueva): verificá afirmaciones con un proceso visible. brain busca primero en tu memoria y sale a internet solo si no alcanza (y lo avisa), lee cada página entera, agrupa las fuentes que no son independientes, busca evidencia en contra y da un veredicto por reglas —respaldada, probablemente respaldada, mixta, no concluyente, probablemente falsa, falsa o no verificable— con citas, fechas y limitaciones. Las preferencias (nivel, actualidad, fuentes primarias, regiones, idiomas, buscador…) se configuran una vez. También /factcheck en el chat y la tool fact_check. No se guarda nada en el vault salvo que toques Guardar en brain.
  • Cambios en el grafo con aprobación: para conectar o desconectar notas, el chat (o un agente) propone el cambio y ves una imagen del grafo con el cambio marcado en verde o rojo. Aprobás, rechazás o deshacés; nada cambia antes de aprobar.
  • Formato de las notas: cada nota lleva ahora type, created y updated (compatible con el Open Knowledge Format), que se completan solos. Ajustes → Formato de las notas los agrega a las notas viejas.
  • El chat puede responder con HTML (tablas, secciones plegables, resaltados, diagramas simples), sanitizado.

Cambios

  • El chat sigue reglas de trabajo más claras: entender el pedido, usar las tools justas, responder con el resultado primero. Ya no repite la misma llamada a una tool, y siempre termina con una respuesta en vez de cortarse cuando se le acaban las vueltas.
  • Las páginas guardadas se parten por secciones y párrafos (los títulos y los bloques de código quedan enteros), y guardan su autor y su fecha cuando la página los muestra.
  • La tarjeta de Manus Studio ya no repite el comando y los argumentos que aparecen más abajo.

DeepSeek Harness, and Manus on your computer

One more agent in one click, Manus back to local, and cloudflared installs on macOS.

New

  • DeepSeek Harness in Connect agent: one click adds brain to ~/.dsh/cordis.patch.yml, which the desktop app and the dsh CLI share. dsh reloads it by itself, so there's no need to quit the app.

Changed

  • Manus Studio connects locally again, like the other desktop apps. Its card shows the command and arguments for its Run a command form, and switches to Detected once Manus uses brain. Manus on the web can still use remote access by URL.

Fixed

  • Installing cloudflared on macOS failed with “The downloaded file doesn't match the published SHA256”. For macOS, Cloudflare publishes the checksum of the program inside the .tgz, not of the .tgz itself; brain now checks that and still refuses anything that doesn't match.

brain by URL

brain is no longer local-only: agents in the cloud or on another computer can connect with a URL. The chat gets your saved skills and knows how the app works, and updating is one click.

New

  • Remote access by URL (Connect agent): publishes brain's MCP server through a Cloudflare tunnel, without opening ports. The URL carries a secret token; you can regenerate it, set it to read-only, and use your own Cloudflare account for a fixed address. brain downloads cloudflared for you and checks it against the SHA256 Cloudflare publishes.
  • Manus Studio and OpenMausBot in Connect agent. OpenMausBot connects in one click; Manus uses the remote access URL, with the steps on its card.
  • Your skills with / in the chat: the skills your agents saved in skills/ show up under “Your skills”, apart from brain's own commands.
  • Fixed app context: the chat always knows how brain works, so it can tell you where things are. You can read it (not edit it) in Settings → System prompt, under your own instructions.
  • System notifications (Settings → Notifications) for uploads, changes and deletions in your vault, made by an agent, the chat or you.
  • Update and restart: a green button next to “Check for updates” when there's a new version. brain closes, updates and reopens, and the page reloads by itself.

Fixed

  • Connect agent and Logs no longer scroll sideways on a phone.

brain por URL

La URL lleva un token secreto; se puede regenerar, poner en solo lectura y usar tu cuenta de Cloudflare para una dirección fija. brain baja cloudflared por vos y lo verifica con el SHA256 que publica Cloudflare.
  • Manus Studio y OpenMausBot en Conectar agente. OpenMausBot se conecta con un click; Manus usa la URL del acceso remoto, con los pasos en su tarjeta.
  • Tus skills con / en el chat: los skills que guardaron tus agentes en skills/ aparecen en «Tus skills», separados de los comandos de brain.
  • Contexto fijo de la app: el chat siempre sabe cómo funciona brain, así te puede decir dónde está cada cosa. Se puede leer (no editar) en Ajustes → System prompt, debajo de tus instrucciones.
  • Notificaciones del sistema (Ajustes → Notificaciones) por cargas, modificaciones y eliminaciones en tu vault, las haga un agente, el chat o vos.
  • Actualizar y reiniciar: un botón verde al lado de «Buscar actualizaciones» cuando hay una versión nueva. brain se cierra, se actualiza y se vuelve a abrir, y la página se recarga sola.

Windows, Linux and connectors that sign in

brain now installs on macOS, Linux and Windows, remote MCP servers that need a login work, the chat can set up connectors for you, and your data can be backed up and restored.

New

  • Windows and Linux. Linux uses the same install.sh command; Windows gets irm …/install.ps1 | iex and a brain-setup.exe installer attached to each release, along with brain-install-linux.sh. GitHub Actions runs the tests and the installers on all three systems on every commit to main.
  • Sign in to MCP servers. Remote servers that answered 401 Unauthorized (Notion, Linear, Sentry…) now show Sign in: it opens the service's own login and brain keeps and renews the token (standard MCP OAuth with PKCE).
  • /add-mcp in the chat: give it a URL or instructions and it reads the docs and proposes the connector. Nothing is added until you click Add and see the exact command or URL. New tools propose_connection and read_url.
  • Backup and restore in Settings: one .zip with the vault, history, settings, connections and what's indexed in Chroma (embeddings included, so restoring doesn't need Ollama). Credentials are left out unless you ask. Restoring saves a copy of the current state first and rebuilds what's missing.
  • Source freshness. Knowledge shows how old each source's content is and when it was last checked. Refresh re-downloads one or all; if it fails, the last good copy stays and the error is shown. New tool refresh_sources.

Fixed

  • The model picker in a new chat shows the context limit set in Settings for each model, instead of 16k for all.
  • Re-saving a URL no longer loses its index if Ollama or Chroma fail halfway.

Memory that ages well

Search that finds exact names, facts with dates, summaries, entities in the graph, and a review that suggests fixes without touching anything.

New

  • Hybrid search. search_knowledge combines semantic search with an exact-keyword index (SQLite FTS5, BM25) merged by reciprocal rank fusion. Proper names, IDs, dates and numbers now show up. If Chroma or Ollama is down, keyword search keeps working.
  • Facts over time. Each memory is saved with its date. add_memory(fact, category, supersede=old) moves the old fact to a ## Historial section instead of leaving both. New tool memory_history(category).
  • Summaries. Pages over 800 words (and long connection results) get a short abstract from your local chat model; list_sources() returns it.
  • Entities in the graph. Sources, captures and memory files get an entities list. Notes that name the same person or project connect through a new Entity node type.
  • distill_skill(topic). Gathers everything brain has on a topic so your agent writes a skill from it.
  • Reflect (Profile tab). Finds duplicates, likely contradictions and notes without entities, and shows the tool call that would fix each one. It never writes.
  • reindex_keyword_search() and a Rebuild keyword index button, for sources saved before this version.
  • Documentation site (Docs) and this changelog.
  • SECURITY.md with how to report vulnerabilities privately.
  • Settings is now a full view: the installed version with a Check for updates button (the gear turns green when a new version is out), sidebar order and visibility, the default chat model, and graph colors.

Changed

  • The dashboard sidebar header shows just the logo and the name, aligned on one row.
  • The website header keeps only the GitHub logo next to the section tabs; Docs, Changelog and GitHub moved to the footer.
  • The license is split in two files, LICENSE (MIT) and COMMONS-CLAUSE.md, so GitHub detects it. The terms don't change.

Upgrade notes

  • Run Rebuild keyword index once (Knowledge tab) so older sources are found by keyword.
  • Summaries and entities need a chat model: ollama pull llama3.2. Without it they're skipped.

Una memoria que envejece bien

Búsqueda que encuentra nombres exactos, hechos con fecha, resúmenes, entidades en el grafo y una revisión que sugiere arreglos sin tocar nada.

  • Hechos en el tiempo. Cada memoria se guarda con su fecha. add_memory(hecho, categoría, supersede=viejo) pasa el hecho viejo a una sección ## Historial en vez de dejar los dos. Tool nueva memory_history(category).
  • Resúmenes. Las páginas de más de 800 palabras (y los resultados largos de conexiones) llevan un abstract corto hecho por tu modelo de chat local; list_sources() lo devuelve.
  • Entidades en el grafo. Fuentes, capturas y archivos de memoria llevan una lista entities. Las notas que nombran a la misma persona o proyecto se conectan por un nuevo tipo de nodo, Entidad.
  • distill_skill(topic). Junta todo lo que brain tiene sobre un tema para que tu agente redacte un skill.

  • Sitio de documentación (Docs) y este changelog.

  • Ajustes ahora es una vista completa: la versión instalada con un botón Buscar actualizaciones (el engranaje se pone en verde cuando sale una versión nueva), orden y visibilidad del sidebar, el modelo por defecto del chat y los colores del grafo.

Cambios

  • El encabezado de la web deja solo el logo de GitHub al lado de las pestañas; Docs, Changelog y GitHub pasaron al pie.

  • Redesigned chat: full-height, floating composer, user bubbles on the right.
  • The collapse button moved next to the logo and name.

Arreglos, y tools para cualquier modelo de chat

Arreglado

  • La pestaña Perfil no cargaba ("list index out of range") cuando un agente reescribía profile.md sin la línea en blanco esperada.
  • Las notas con frontmatter YAML inválido (un : sin comillas en una description) perdían la description en el grafo sin avisar. Ahora cada escritura valida el frontmatter, lo repara si puede o rechaza la escritura con un error claro; las lecturas nunca se rompen.

Nuevo

  • set_frontmatter(path, fields): cambiar metadatos sin reescribir la nota.
  • Las tools del chat andan con cualquier modelo: los esquemas se limpian, y los modelos que rechazan tools nativas (GGUF de Hugging Face) pasan a un modo texto con bloques <tool_call>.

First release

  • MCP server with a Markdown vault: read, write, append, replace and delete notes; profile and memory; skills.
  • Save the web: save_url with trafilatura and a Playwright fallback for JavaScript sites; semantic search with Ollama (nomic-embed-text) and a shared Chroma server.
  • Version history in SQLite: file_history and restore_file, safe with several agents writing at once.
  • Dashboard (brain): service switches, metrics, system health, profile and memory import, graph, knowledge and logs, in English and Spanish.
  • Connect agent in one click: Claude Desktop, ChatGPT, Claude Code, Codex, Cursor, VS Code, Windsurf and Gemini CLI.
  • Connections: brain as an MCP client of other servers (local command, URL or Composio, with consumer and project keys), with results captured to memory.
  • One-command installer and website.

Primera versión

  • Server MCP con un vault en Markdown: leer, escribir, agregar, reemplazar y borrar notas; perfil y memoria; skills.
  • Guardar la web: save_url con trafilatura y fallback a Playwright para sitios con JavaScript; búsqueda semántica con Ollama (nomic-embed-text) y un server de Chroma compartido.
  • Historial de versiones en SQLite: file_history y restore_file, seguro con varios agentes escribiendo a la vez.
  • Dashboard (brain): switches de servicios, métricas, salud del sistema, perfil e importación de memoria, grafo, conocimiento y logs, en español e inglés.
  • Conectar agente en un click: Claude Desktop, ChatGPT, Claude Code, Codex, Cursor, VS Code, Windsurf y Gemini CLI.
  • Conexiones: brain como cliente MCP de otros servers (comando local, URL o Composio, con keys de consumidor y de proyecto), con los resultados capturados en la memoria.
  • Instalador de un comando y sitio web.
