# Landing page (docs/index.html)

Mode: Persuade. Audience: people who use AI chat apps daily (non-developers first). Action: copy the install command; secondary: open the GitHub repo. Proof: HTML recreations of the real product (memory cards, Connect agent, dashboard graph); no invented users, numbers or quotes. Constraints: monochrome black-and-white, EN/ES toggle, one static HTML file for GitHub Pages.

## Direction contract

THESIS: The page is a working slip-box. brain's memory is a drawer of typed index cards, cross-referenced by Luhmann-style numbers (1, 1a, 1a3), and every AI agent is one more card pointing at the same memory. It refuses the dark developer-tool hero with a glowing terminal and the grid of identical feature cards.

OWN-WORLD: White card stock and black typewriter ink only. Cards with a hairline ruled header line, a reference number top-right, and a typed body. Drawer tabs as navigation and section markers. Rubber-stamp outlined caps for status (CONNECTED, LOCAL). Pencil-thin reference lines between cards. Archivo for display and body, Courier Prime only for what is literally typed on cards or entered in a terminal.

STORY: Your AIs each forget you and don't share what they know. brain gives all of them one memory that lives on your Mac. It installs with one command and connects with one click. Copy the command.

FIRST VIEWPORT: Left, about 6 of 12 columns: a large headline, one line of subcopy, the install command as a typed card with a copy action, and a GitHub link beside it. Right: a card spread. The central card "1 · brain" holds typed memory entries; agent cards (Claude 1a, ChatGPT 1b, Cursor 1c, Claude Code 1d) sit around it, each with a reference line into card 1. Top bar: wordmark, section tabs, EN/ES tab switch.

FORM: Zettelkasten slip-box; IMPECCABLE'S PICK (my #1 grounded candidate, chosen over the assigned #6); seed f9010b46. Signature interaction: hovering or focusing an agent card inks its reference line and highlights the memory entries it reads. Motion: the cards file out of the drawer once, on load.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
